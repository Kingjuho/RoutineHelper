# RoutineHelper icon

Generated using the built-in image_gen tool. The PNG retains the generated alpha channel; the ICO packages resized PNG frames at 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixels. Both files are project assets. The ICO is embedded in the application and used for its executable, tray and settings window.

## Final generation prompt

Use case: logo-brand. Create a minimal Windows tray app icon for a routine timer. EXACTLY ONE simple flat teal clock OUTLINE on a truly transparent PNG canvas. The clock is a thick perfectly circular ring, with EMPTY transparent center, and two thick straight clock hands attached at center pointing UP and RIGHT. All visible shapes are the same single solid bright teal color. Uniform opaque flat color, sharp smooth edges. Bold stroke thickness about 11% of icon diameter, readable at 16 pixels. Center the icon with only 8% transparent padding around it. No disk fill, no extra badge, no text, no numbers, no gradients, no texture, no lighting, no shadow, no 3D, no mockup, no background. Pure simple flat pictogram made of a single circular ring and two hands on transparent background.
